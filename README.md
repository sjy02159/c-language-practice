## Projects List

### 1. Narcissistic Number Finder
A simple C program to find all "narcissistic numbers" between 100 and 999.

- **File:** `narcissistic_number.c`
- **How it works:** Uses a `for` loop to iterate through numbers from 100 to 999, separates the digits using modulo (`%`) and division (`/`), and checks if the sum of the cubes of its digits equals the number itself.

#### How to compile and run
```bash
gcc narcissistic_number.c -o narcissistic
./narcissistic
